# RVP Photography Portfolio

A simple static photography portfolio website built with HTML and CSS. It showcases a clean, modern gallery layout with a sidebar navigation, hero section, and multiple photo collections.

## Features

- Full-screen landing section with overlay background
- Minimal sidebar menu with animated open/close interaction
- Modern gallery grid for image showcases
- Responsive layout for desktop and smaller screens
- Custom typography and icon styling

## Project Structure

- `photogrphy.html` - Main webpage structure
- `photography.css` - Styling and layout
- `assets/` - Project images and gallery photos

## Run Locally

1. Open `photogrphy.html` in your browser directly, or
2. Serve the folder locally using a simple HTTP server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

- This is a front-end-only project.
- No build tools or dependencies are required.
- Images are stored locally in the `assets` folder.
